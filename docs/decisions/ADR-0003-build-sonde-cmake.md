# ADR-0003 — Build de la Sonde : CMake contre les sources RE-UE4SS, workspace hors monorepo

- **Date** : 2026-08-01
- **Statut** : accepté
- **Contexte** : la Sonde est un mod C++ UE4SS et se compile contre les sources de RE-UE4SS (fork Okaetsu). L'écosystème UE4SS actuel utilise **CMake** (≥ 3.22, générateur MSVC ou Ninja, toolchain Rust requise pour la dépendance patternsleuth) — conforme au §7 du cahier des charges. Modèle de référence : PalSchema (Okaetsu), mod C++ open source qui suit exactement ce schéma (`add_subdirectory` de RE-UE4SS, `add_library SHARED`, link `UE4SS`).
- **Contrainte découverte** : le sous-module `deps/first/Unreal` (UEPseudo) de RE-UE4SS est un **dépôt privé, gated par l'EULA Epic Games**. Le compiler exige un compte GitHub lié à un compte Epic Games (accès source Unreal Engine). Conséquence : la CI publique ne pourra pas compiler la Sonde sans secret d'authentification dédié — point à traiter à la mise en place des GitHub Actions.
- **Décision** :
  1. Build de la Sonde en **CMake**, calqué sur le schéma PalSchema.
  2. Layout : les sources de la Sonde vivent dans le monorepo (`probe/OverkitProbe/`) ; le clone de RE-UE4SS vit **hors monorepo** dans un workspace local (`../probe-workspace/`) qui référence les sources du monorepo par jonction NTFS. Le monorepo ne contient ni sous-module lourd, ni binaire, ni code gated Epic.
  3. Le commit de RE-UE4SS utilisé doit correspondre au build UE4SS installé dans le jeu (compatibilité ABI) ; le SHA est consigné dans `probe/README.md` à chaque montée de version.
- **Conséquences** : la sortie du mod est `Mods/OverkitProbe/dlls/main.dll`. La question CI (accès UEPseudo) est reportée à la Phase 1.
- **Suivi du blocage UEPseudo (2026-08-01)** : le compte de dev a l'accès UE source via l'org miroir `EpicGames-Mirror-A` — système introduit par Epic le 10/06/2024 (« Maintenance on the Epic Games GitHub Organization », forums Epic), dont la limitation documentée est précisément que les membres miroir n'accèdent pas aux forks de l'org d'origine, dont `UEPseudo` (fork privé de `EpicGames/UnrealEngine`). Un message Discord UE4SS du 27/06/2024 annonçait une réversion par Epic, jamais confirmée dans le fil officiel ; le compte étant toujours dans Mirror-A en 2026, le blocage est réel. Pistes actives : (1) dissocier/relier le compte GitHub sur epicgames.com pour retenter l'affectation à l'org principale ; (2) demande à jour sur le Discord UE4SS. En attendant, la lecture par réflexion est dérisquée via un spike Lua (`probe/spike-lua/`). Test de déblocage : `gh api repos/Re-UE4SS/UEPseudo` (succès = `git submodule update --init --recursive` dans le workspace, puis build CMake).
